# 物体認識論最終レポート

2026年度 物体認識論 最終課題のソースコードです。

## 概要
* **課題1:** 画像の分類精度比較
* **課題2:** Web画像検索結果のリランキング

## 動作環境
* MATLAB online R2025b

## 使い方
1.  「最終レポート」という名前のディレクトリを作成し、その直下にすべてのファイルを置いてください。解凍したbgimgのディレクトリも忘れずにこの直下に置くようにしてください。
2.  まずmakeLimg関数を実行してください。
3.  次にrepo1関数を実行してください。これで課題1は終了です。
4.  最後にrepo2関数を実行してください。これで課題2は終了です。
5.  二回目以降に実行する場合はディレクトリを消したりしていなければrepo1関数から始めてもらって大丈夫です。
